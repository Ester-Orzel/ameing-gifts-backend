# אפיון: אתר מתנות במיתוג אישי (Ameing)

מסמך האפיון שאושר לפני הבנייה, כולל ההחלטות שהתקבלו בשיחה.

## א. תיאור הפרויקט

- **שם:** Ameing, מתנות במיתוג אישי.
- **מטרה:** לקוחות בוחרים מתנות, מתאימים להן הדפסה אישית (שם או אות, גופן וצבע) ושולחים הזמנה עם כמה פריטים יחד. בעל העסק מנהל את המוצרים ואת ההזמנות במקום אחד.
- **קהל יעד:** הקהל הרחב.
- **משתמשים:** לקוח (נרשם, מזמין, עוקב אחרי ההזמנות שלו), ומנהל (בעל העסק).

**החלטות עסקיות:**
- אין תשלום באתר. בעל העסק יוצר קשר טלפוני לתשלום. באתר מוצג הסכום הכולל.
- כל פריט בהזמנה הוא מוצר אחד עם הדפסה משלו. אין שדה כמות.
- הלקוח בוחר משלוח או איסוף עצמי. כתובת נדרשת רק במשלוח.
- גלישה במוצרים אפשרית בלי התחברות. כדי להוסיף לסל צריך להתחבר.
- הסל נשמר בצד ה-React, ונשלח לשרת בבקשה אחת.
- הלקוח לא עורך ולא מבטל הזמנה. רק המנהל משנה סטטוס.
- המחיר מחושב בשרת לפי המחיר במסד הנתונים.
- גופנים וצבעים הם רשימה אחת משותפת לכל המוצרים, והמנהל יכול לעדכן אותה.

## ד. מסד הנתונים

ראי `prisma/schema.prisma` ו-`README.md`. 7 טבלאות: `users`, `categories`, `products`, `fonts`, `colors`, `orders`, `order_items`.

**סטטוסים:** `RECEIVED` התקבלה ← `IN_PROGRESS` בהכנה ← `READY` מוכנה ← `DELIVERED` נמסרה, וגם `CANCELLED` בוטלה. נמסרה ובוטלה הן סופיות.

**כללי הדפסה:**
- `NONE`: אין טקסט, גופן או צבע.
- `NAME`: רק במוצר `NAME_OR_INITIAL`. 2-20 תווים, אותיות בעברית/אנגלית, רווחים, מקף או גרש. גופן וצבע חובה.
- `INITIAL`: אות אחת. גופן וצבע חובה.
